Floe — the commands pane with seven commands

Seven commands, every state the pane knows (running, starting, crash-looping, exited 0, never ran, stopping), names from 2 to 25 characters and command lines from 12 to 140. Every pane is focused with the cursor on queue, at the panel's real width (300px default, 240px minimum).

F1 No key for Run all / Stop all. They exist only as palette entries and as mouse chips.
F2 The stop icon is pixelarticons debug-stop: a bug with a square on it. The play glyph is 8×16 on a 24 grid, so at 13px it reads as a sliver, and it doubles as the panel's own icon.
F3 When the name equals the command (your pnpm run dev) line two repeats line one.
F4 Row buttons sit on line two while the scope chip sits on line one, so the row has two right edges. The header chips appear and disappear with state, so Run all jumps sideways.
F5 Stop all ignores starting: it is disabled and hidden while a command is only starting, which is exactly when you press it after a bad Run all.
F6 Seven two-line rows plus two headings need ~400px. On a stacked panel the list scrolls before you see the stopped block.
F7 Today's grid lets a long command line push the row buttons past the panel edge (queue, vite, stripe in O0). .cmd-l2 has no min-width: 0, so the 1fr column grows to the unwrapped command.
